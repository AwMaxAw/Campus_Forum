## 二、本版本核心功能里程碑（内测期已完成）

### 🏫 基础架构
- 4 个标准分区：广五本部初中部(2611)、广五本部高中部(2612)、金碧校区初中部(2621)、金碧校区高中部(2622)
- UID 前 4 位自动绑定分区，顶栏下拉框可查看，非对应权限会提示无权限选择并自动回滚

### 📖 社区核心
- 发帖（支持图片上传至 R2，含压缩）、评论、回复、点赞、收藏、搜索、置顶帖
- 广场 2 种视图：**卡片**（默认 3 列九宫格，置顶帖混排最前）/ **列表**（置顶折叠区 + 时间线）
- 每条帖子 / 评论 / 公会 / 用户均显示编号（卡片右下角、详情页 meta、评论头部），可精确定位

### 👤 用户体系
- 注册 + 登录（JWT + bcrypt），头像（系统头像可选）、昵称、个人主页（发帖 / 评论统计）
- 等级经验值：发帖 +5、评论 +1、点赞帖子 +1、每日首次登录 +2；Lv 对应积分段实时换算
- Lv 徽章：所有发帖/评论/私信列表/个人主页都显示，`ops_admin → Lv.999`、`admin → Lv.888`

### 🔐 管理员权限分层
- **运维管理员（ops_admin，UID 00000001，Lv.999）**：最高权限
  - 发帖时可下拉选择分区；可直接删帖 / 删评 / 封禁用户 / 封禁公会
  - 面板：已注册账号（改等级/积分）、公会面板（增删改人/注销/封禁）、**待审批申请板块**（通过并执行 / 拒绝）
- **管理员（admin，UID 26120001 / 26120002，Lv.888，密码 admin1234）**
  - 权限范围：仅广五本部高中部(2612)，无法切换其他区
  - 显示：蓝色「管理员」角色徽章 + Lv.888
  - 能力：只能**提交申请**（删除帖 / 删除评论 / 封禁用户 / 封禁公会），需运维管理员审批
  - 新导航入口「📝 管理员面板」：
    - 顶部：📜 **管理员守则**（可折叠，6 大章节）
    - 申请板块 × 2：删除帖/评论（填编号+理由）、封禁用户/公会（填 UID/ID+理由）
    - 详情页快捷按钮：帖子详情「申请删除」、每条评论「申请删除」、用户主页「申请封禁」、公会详情「申请封禁」（自动预填目标 id）
    - 下方：⏳ **待通过**、✅ **已执行 / 已拒绝**（历史含审批备注）
- 数据：新增 `admin_requests` 表（type / target_id / snapshot / reason / requester / status / reviewer 等），状态机 `pending → approved/rejected`，审批通过时同一事务内执行删除 / 封禁动作

### 🎁 积分 & 签到
- 积分页面顶端签到板块：显示今天日期 + 签到按钮
- 签到日历（缩小版）+ 连续签到天数
- 签到规则：**基础 3 分/天，每连续 7 天额外奖励 2 分**
- **签到后**自动显示今日运势（大凶😱/小凶😟/中平🙂/小吉😊/大吉🎉），没签到不显示

### 🔔 通知 & 私信
- 顶栏"消息"：系统消息（发帖加积分、签到加积分、管理员处理结果等），实时未读红点
- 私信：列表含头像 / 昵称 / Lv / 公会徽章、右侧对话气泡；支持 **Ctrl/Cmd + Enter 发送**
- 所有用户私信列表顶部**固定置顶 00000001 运维管理员对话**

### 🏛 公会系统
- 导航栏"公会"：公会列表（含图标 / 简介 / 成员数）、创建公会、一键加入 / 退出、加入申请审批
- 用户发帖 / 评论 / 私信列表 / 顶栏头像旁 / 已注册账号列表 / 个人主页 —— 昵称前都有**公会徽章**
- 运维公会面板：编辑公会名称 & 图标 & 简介、注销 / 封禁公会、成员管理（加人 / 踢人 / 移交会长）、加入申请审批、定位申请审批

### 📰 其他
- 公告栏、反馈通道、关于本站、管理员命令文档
- 运维发历史帖子手动设置 region = 2612，使高中部用户可见

## 五、后续维护建议

1. 每次重大迭代在 `backup/` 下新建同级快照目录（如 `v1.1.0-<描述>-<日期>`），不要覆盖本目录。
2. 上线前先做最小化回归：登录 26120001 → 提交删除申请 → 切 00000001 审批 → 验证帖子被软删。
3. 若 D1 表结构变更，`schema.sql` 同步更新后 Worker 的 `autoMigrate()` 会在启动时自动补建。
